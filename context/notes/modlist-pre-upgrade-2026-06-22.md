> every world load, so this record was about to be destroyed (current `enabled.json` is

**Provenance.** Restored from the old machine via tModLoader config sync (Steam Cloud);
mtime was today but content is the old stack. Corroborated by the v0.5 perf baseline,
which named `CheatSheet`, `Verdant`, and `BossChecklist` as top contributors — all present
here at the same versions.

**Note on scope.** This 99-mod list is the *play* stack. It is NOT the lean **18-mod
benchmark stack** the v0.6 perf research measured against (71.6% hook coverage, `0.12 ms/tick`).
"What we benchmarked" and "what was played" were two different sets.

**Versions are as-launched.** Re-subscribing via Workshop pulls *current* versions, which
will differ (this is a month+ old, possibly across a tModLoader patch). Expect a few
out-of-date / disabled on first load.
